from scripts.auto_summary import AutoSummarizer

loader = MemoryLoader('memory_local/qa_agent')
summarizer = AutoSummarizer('memory_local', 'config.local.yaml')

# 加载记忆

📞 常见问题
========================================================================

Q: 为什么记忆文件不在 GitHub 上？
A: 设计如此！记忆文件是私有本地数据，已在 .gitignore 中排除。

Q: 如何在另一台电脑上使用？
A: 克隆 GitHub 仓库，运行 start.bat/start.sh 即可。
   本地记忆会在你的电脑上独立创建。

Q: 可以共享记忆吗？
A: 不建议。每台电脑应该有独立的记忆。
   可以备份 memory_local/ 目录进行迁移。

Q: 依赖安装失败了怎么办？
A: 手动运行: pip install pyyaml

Q: .gitignore 配置错误了？
A: 检查: cat .gitignore | grep memory_local
   应该包含 memory_local/
