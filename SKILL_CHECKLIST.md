## ✅ Known Limitations & Mitigations

### Limitation: No Built-In Persistence to External DB
**Mitigation:** Markdown storage is version-controllable; users can add DB layer if needed

### Limitation: Sync Between store.md and reflect.md is Manual
**Mitigation:** Keep both files always in sync (documented); plan for atomic writes in V2

### Limitation: No Learned Gate (Still Rule-Based)
**Mitigation:** Rule-based sufficient for MVP; planned for V1.1

### Limitation: No Multi-Expert Routing (Only 2 modes)
**Mitigation:** Dual-mode sufficient for MVP; roadmap for V2.0

### Limitation: No Automatic Archiving
**Mitigation:** Documented cleanup procedures; can be scripted by users
